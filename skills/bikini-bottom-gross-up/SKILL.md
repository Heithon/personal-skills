# Bikini Bottom Gross-Up

比奇堡特写：让原图主体保持可辨认的美式卡通形体，并用精细的手绘材质细节制造荒诞、滑稽、略有不适感的静态插画。

## 判断交付内容

- 用户要求转换已提供的图片时，按图像编辑任务执行。
- 用户只要求编写、优化或翻译提示词时，只交付提示词，不启动图像生成。
- 图片转换缺少目标图片时，请用户提供图片；通用提示词任务不需要图片。
- 多图输入先区分编辑目标、风格参考与构图参考。只将用户指定的对象视为编辑目标；存在会影响结果的歧义时再询问。

## 执行方式

1. 查看编辑目标；仅有本地路径时先打开图像。识别主要对象、材质、原有风格、视觉焦点以及必须保留的身份与结构特征。
2. 读取 [references/prompt-template.md](references/prompt-template.md)。它包含完整的风格要求、材质分支和可复制的通用母版。已有适用的风格说明时，无需重新联网研究。
3. 按原图与用户要求改写母版。针对一张具体图片时，只保留适用的主体和材质分支；交付通用提示词时保留条件分支。将“主体”等泛称替换为已观察到的对象，明确本次必须保留的特征。
4. 使用当前环境提供的图像编辑工具，并遵循该工具的参考图输入规范。把原图作为编辑目标传入，不能仅凭文字描述重建身份。工具不可用时，说明尚未生成图像，并交付可用提示词。
5. 检查输出的卡通形体、主体辨识度、绘画质感、细节分布与幽默感。若需要迭代，针对具体偏差调整提示词，并重申必须保留的特征。

## 默认设置

用户的明确选择优先；其余使用：

- 构图：自动适配。单一主体倾向近景或特写；合照、多主体与风景优先保留关系和布局。
- 怪诞程度：中等，保留滑稽感。
- 形变程度：中等，以主体可辨认为前提。
- 画幅：沿用原图比例。
- 表情：保留原有情绪的基本含义，适度强化不对称与尴尬停顿感。

这些是自然语言创作偏好，不是图像工具的专用 API 参数。已能从请求和图片判断时，不必逐项询问。

## 关键判断

- 保持二维手绘动画插画。所有体积、油光、湿润感与微观细节都通过画出来的线条、笔触、色块和明暗表达。
- 保留主体类型、身份特征、标志性轮廓与重要对象关系。允许有趣的形变，不把所有人变成老人，也不把动物或物件统一套成人脸。
- 将精细刻画集中在适合的部位，保留大形体与较安静的色块。怪诞感来自对该对象特征的夸张。
- 采用这类特写的绘画语言，不自动添加海绵宝宝角色、黄色海绵身体或海底背景。
- 用户要求不同的构图、怪诞强度或保留项时，以其明确要求为准。若用户将目标改为摄影写实或其他风格，不再强行套用本 skill。

## 完成检查与交付

检查主体是否仍可辨认，画面是否一眼可读为卡通，以及细节是否呈现统一的绘画质感。留意无理由新增的五官、主体数量变化、破坏互动的裁切、全图噪点、恐怖化或照片材质残留。

图片任务展示生成结果，并简短说明实际完成的转换；需要保存时沿用用户指定位置。提示词任务交付可复制的文本，用用户使用的语言表达，不声称已经生成或测试图片。
